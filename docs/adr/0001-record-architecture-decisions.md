# 0001 — Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-10-17

## Context
Cutpay is a learning project. The reasoning behind a choice is often more valuable than the choice itself, and we will revisit decisions as phases progress.

## Decision
We keep lightweight Architecture Decision Records (ADRs) in `docs/adr/`, numbered sequentially, using the format *Context → Decision → Consequences*. A superseded ADR is not deleted; its status changes to `Superseded by NNNN`.

## Consequences
- Every non-obvious technical choice gets an ADR in the same pull request that introduces it.
- The decisions table in `docs/plans/README.md` links here.
